## Day-by-Day Commands

### Day 1 — Environment + Dataset (~2 hours)
```bash
# 1. Run setup (as Administrator on Windows)
setup.bat

# 2. Verify GPU detected
python -c "import torch; print(torch.cuda.is_available())"
# Expected: True

# 3. Download and prepare dataset
python data/prepare_dataset.py
# Expected: train.csv, validation.csv, test.csv created
```

**What you'll have:** Python environment ready, 18,000+ labelled emails split into train/val/test.

---

### Day 2 — Pre-trained Model Test (~1 hour)
```bash
python notebooks/day2_quick_test.py
```
**What you'll see:** BERT predictions on 8 test emails. Expected accuracy: ~85-90% (without any training by you). This proves the pipeline works before you spend time training.

---

### Day 3 — Fine-tune on Your Data (~1-3 hours)
```bash
python notebooks/day3_finetune.py
```
**What you'll see:** Training progress bar for 3 epochs, validation metrics after each epoch, model saved to `models/phishguard-bert-finetuned/`.

**If you get CUDA out of memory:**
- Open `day3_finetune.py`
- Change `'batch_size': 16` to `'batch_size': 8`
- Change `'max_length': 256` to `'max_length': 128`

---

### Day 4 — Flask API Backend (~2 hours)
```bash
python backend/app.py
```
**Then test it** by opening in your browser:
```
http://localhost:5000/api/v1/health
```
Expected response:
```json
{"status": "ok", "model": "phishguard-bert-finetuned", "device": "cuda"}
```

**Test the analysis endpoint** (use Postman or curl):
```bash
curl -X POST http://localhost:5000/api/v1/analyse \
  -H "Content-Type: application/json" \
  -d "{\"content\": \"URGENT: Verify your PayPal account NOW\", \"input_type\": \"email\"}"
```

---

### Day 5 — Connect to PhishGuard Frontend (~2 hours)

1. Open `PhishGuard_AI.html` in VS Code
2. Find this line near the bottom of the file:
   ```javascript
   async function callClaudeAPI(content, inputType, headers) {
   ```
3. Add this line just before the `<script>` tag at the bottom:
   ```html
   <script src="frontend-patch/bert_connector.js"></script>
   ```
4. Find the `runAnalysis()` function and replace `callClaudeAPI` with `runAnalysis_BERT` by adding this one line at the top of the function:
   ```javascript
   // Replace existing runAnalysis with the BERT version
   ```
   
   Or simpler — just add this to the bottom of your `<script>` block:
   ```javascript
   // Override the analyse button to use BERT
   document.getElementById('analyse-btn').onclick = runAnalysis_BERT;
   ```

5. Open `PhishGuard_AI.html` in your browser
6. Check the status bar at the bottom — should show **green dot** + "BERT backend connected"

## Troubleshooting

| Problem | Fix |
|---|---|
| `CUDA out of memory` | Reduce `batch_size` to 8 in day3_finetune.py |
| `ModuleNotFoundError: transformers` | Re-run `setup.bat` as Administrator |
| `ConnectionRefusedError` on frontend | Make sure `python backend/app.py` is running |
| BERT status shows red in browser | Backend not running — open a new terminal and run `python backend/app.py` |
| Day 2 model not found | It downloads automatically — check internet connection |
| `True` not printed for CUDA | Visit pytorch.org → Get Started → match your CUDA version |

## What BERT learns vs your heuristics

| Signal | Heuristic (regex) | BERT |
|---|---|---|
| "paypa1" typosquat | ✓ explicit rule | ✓ learned from examples |
| Novel brand impersonation | ✗ not in rules | ✓ generalises |
| Subtle urgency tone | ✗ keyword only | ✓ understands context |
| Legitimate security email | ✗ often false positive | ✓ understands intent |
| New phishing template | ✗ misses completely | ✓ generalises to pattern |
